# Unit 2 Chapter 4 Question 6 - Stop Light
Traffic systems and commerce in many parts of the world are dependent on traffic lights to keep things running smoothly.

Since elementary school, you've learned that 'green' means 'go', yellow means 'prepare to stop', and red means 'stop'. 

Write a program that reflects this association between a traffic light's colour, and the behaviour that drivers approaching the
traffic light should have.

Traffic lights may also flash red, shine a green arrow for an advanced turn, or not work at all. Account for these situations as well. 

## Input Specification
The input consists of a single line containing the traffic's current colour or state state (ie, completely off).

## Output Specification
Output the action that an oncoming driver should take when approaching the light.

- If the light is `green`, the driver should `proceed`.
- If the light is `yellow`, the driver should `prepare to stop`.
- If the light is `red`, the driver should `stop`.
- If the light is any other colour or state, the driver should `proceed with caution`.


## Sample Input 1

```
50000.00
```

## Sample Output 1

```
1
```

## Explanation for Sample Output 1

A salary of $50000.00$ is less than or equal to $55,867$, placing it in the first tax bracket.

## Sample Input 2

```
111733.00
```

## Sample Output 2

```
2
```

## Explanation for Sample Output 2

A salary of $111733.00$ is greater than $55,867$ but less than or equal to $111,733$. Therefore, it falls into the second tax bracket.
